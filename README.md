# Open Vibe

**One API key, every AI model.**

Open Vibe is an AI API marketplace and aggregator. Access LLMs, image generation, video, audio/voice, and code models through a single unified API and polished dashboard.

## Features

- Landing page with clear value prop
- Auth UI (sign up / login, email + OAuth placeholders)
- Dashboard with usage charts and top models
- Model catalog filterable by category
- API key management (generate, copy, revoke)
- Usage & billing with per-model cost breakdown
- Pricing tiers (Free, Pay-as-you-go, Pro)
- Docs and interactive playground

## Design

Dark theme with deep green / emerald accents. Clean modern SaaS aesthetic.

## Tech

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Recharts
- Lucide React
- Geist font

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy on Vercel

Import this repo in Vercel. No env vars required for the demo UI.
